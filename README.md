Resubmit: a stronger, fresher one-line excuse an AI agent gives its human for missing a deadline.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
I trained on every deadline excuse ever written, and this is the best one I generated: the Wi-Fi ate my homework.
```
